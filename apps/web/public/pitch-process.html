Two clocks

A quarter to lock the motion. Then we run it on purpose.

Days 1–90 · Activation

Prove the machine

We find, paper, brief, and ship a first cohort. Target: commercially reasonable efforts to onboard up to three creators. You leave the quarter with a roster, a message that has been in market, and a paper trail — not a strategy deck.

Day 91+ · Always-on

Repeat what converted

Briefs get shorter because the story is dialed. Campaigns get more consistent because contracting, UTMs, and reporting already exist. We scale spend and roster on the same category story — not a rebrand every month.

The commercial split stays the same in both clocks: a management fee to run the arm, a media envelope to book the voices. This walkthrough is the work, not the invoice.

Phase 1 target: commercially reasonable efforts to recruit and onboard up to three creators. That is a working cohort — not a promise that three posts exist on day 14.

Days 15–45 · Contract + Brief

Paper the deal. Write the rails. Production can start.

Function · Contract

Rate, usage, deliverables

We negotiate creator rates, usage windows, and what actually ships. You see the terms. We hold the paper trail on Verza — including payouts when work is accepted.

Function · Brief

Messaging + brand safety

Talking points, proof, and what they must not say. The creator still sounds like themselves. Your claims stay accurate. This is the pack that later campaigns reuse.

If the brief needs an anchor — a long-form conversation or flagship piece — it is scoped here so native posts have something real to react to, not a slogan.

Days 46–90 · Ops + Track

Ship on a calendar. Prove it went live. Read the cohort.

Function · Deliverable ops

Dates, posting, UTMs

Timeline management, posting verification, unique links and promo codes per creator. If it did not go live, it is not “delivered.”

Function · Analytics

The platform is the close-out

You get cohort and performance tracking in Verza — views next to clicks and conversions where the offer supports it. The quarter ends with what to scale, not a screenshot dump.

Day 91 onward

The loop does not restart. The message gets cheaper to run.

What is already done

Rails exist

Contracts, usage language, UTM scheme, and a brief that has been in market. We are not inventing a process — we are booking the next wave against a known story.

What changes

Cadence, not category

More consistent campaigns: same talking points, tighter targeting, more ship dates. If Phase 1 proved LinkedIn and X, we do more of that before we invent a new channel mix.

Track → Brief → Source is now a monthly rhythm. You still approve faces. We still operate the arm. The difference is speed: the first quarter paid for the setup.
